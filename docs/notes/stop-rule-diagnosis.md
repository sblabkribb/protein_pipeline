# coverage 정책의 STOP 규칙은 목표 상태에서 발동한다

> **판정이 아니라 진단이다.** `coverage-preserving-prespec.md` 의 주 종점은
> `40_` 이 낸다. 이 문서의 어떤 수치로도 그 사전지정을 고치지 않는다.

작성 2026-09-27, **전수 격자 폴딩이 끝나기 전에.** 주장 1 은 관측을 쓰지
않으므로 결과를 보고 역산한 것이 아님을 이 시점이 보증한다.

## 주장 1 — 해석적. 자료가 필요 없다.

백본 k 개의 feasible mass 가 균등하면 `f = (n, ..., n)` 이고 `EFBC(f) = k` 다.
어느 한 곳에 1 을 더하면 분포가 균등에서 멀어져 엔트로피가 **엄격히** 줄므로

```
EFBC(f + e_b) - EFBC(f) < 0     모든 b
A_b = q_b * (음수) <= 0         q_b >= 0
=> max_b A_b <= 0               => STOP
```

**one-step myopic EFBC 정책은 자기 목적함수의 최적점에서 스스로 멈춘다.**
`45_.analytic_check` 가 k=2..12, n=1..40 격자에서 부호를 직접 확인한다
(최대 이득 -1.5e-4).

이것은 이 코호트의 성질이 아니라 acquisition 의 성질이다. 엔트로피류 목적에
`max A <= 0 -> STOP` 을 붙이면 어디서나 같은 일이 생긴다.

## 주장 2 — 그 상태에 자주 닿는다

```
B=126 · (표적,seed) 130 회 중 STOP 122 (94%)
STOP 시점 f 의 최대/최소 중앙 1.00 · 완전 균등 73%
평균 호출 41.4 / 126
```

warm-up 4/백본이 대개 모든 백본에 성공을 하나 이상 남기므로, 정책은 몇 수
안에 균등에 도달하고 거기서 멈춘다.

## 주장 3 — 멈춘 대가 (탐색적)

STOP 만 뺀 판을 같은 격자에서 재생했다. **가드레일이 실패한 것을 본 뒤에
돌렸으므로 확증 주장으로 쓰지 않는다.**

```
B=126      EFBC   struct 수확   호출    가드레일 비율   LCB95
STOP 유지  4.15      15.14      41.4      0.217        0.204
STOP 제거  4.17      63.51     120.5      0.912        0.851   기준 0.90
EFBC 차이  +0.023 [-0.029, +0.101]   0 포함
```

두 가지를 정확히 적는다.

1. **EFBC 는 달라지지 않는다.** 차이 구간이 0 을 포함하고 B=168 에서는 부호가
   바뀐다. STOP 은 목적함수를 지켜주지 못한다.
2. **가드레일은 여전히 통과하지 못한다.** 점추정 비율은 0.912 지만 사전지정이
   요구하는 것은 단측 95% 하한 >= 0.90 이고 그 값은 0.851 이다. 네 예산 모두
   미달이다 (0.873 / 0.830 / 0.851 / 0.897).

따라서 STOP 제거는 **실패의 성격을 바꾸는 것이지 결과를 구제하는 것이
아니다.** 구조적 불가능(LCB 0.204)에서 근소한 미달(LCB 0.851)로 옮길 뿐이다.
사전지정 §5 가 금지한 "뒤에서 수확 정책으로 fallback 하여 구제" 에 해당하지
않도록, 이 결과로 채택 판정을 뒤집지 않는다.

## 보고 방식

```
주 판정      40_ 의 동결 결과 그대로. coverage mode 가 acceptance criterion 을
             충족하지 못했다.
기전         주장 1 (해석적) + 주장 2 (빈도). 여기까지가 자료에 의존하지 않거나
             단순 관측이다.
탐색         주장 3. 탐색적이라고 명시하고, 확증 주장으로 쓰지 않는다.
```
